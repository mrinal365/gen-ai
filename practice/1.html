1. Tokenization using tiktoken

Tokenization converts text into tokens (integer IDs) that an LLM can process.

For example:

"The cat sat on the mat"

The tokenizer splits the text into tokens and maps each token to an ID. A token might represent a whole word, part of a word, punctuation, or whitespace.

Input text

"The cat sat on the mat"

Tokenizer

Splits text into tokens

Token IDs

[976, 9059, 10139, ...]

The exact token IDs depend on the tokenizer encoding. The numbers shown in your screenshot are examples, not universal IDs for every model.

Main code: tokenization.py

Install the package:

pip install tiktoken
import tiktoken

# Get the tokenizer encoding associated with GPT-4o
encoder = tiktoken.encoding_for_model("gpt-4o")

# Number of token IDs in this encoding's vocabulary
print("Vocabulary size:", encoder.n_vocab)

# Text to tokenize
text = "The cat sat on the mat"

# Convert text into a list of integer token IDs
tokens = encoder.encode(text)
print("Tokens:", tokens)

# Convert the token IDs back into readable text
decoded = encoder.decode(tokens)
print("Decoded:", decoded)

# Count tokens, useful for estimating input size
print("Token count:", len(tokens))

Expected output structure:

Vocabulary size: <vocabulary size>
Tokens: [integer IDs ...]
Decoded: The cat sat on the mat
Token count: <number of tokens>

Your actual token IDs and vocabulary size should come from running the code. n_vocab is the encoding's vocabulary size, not the number of tokens in your sentence.

Important tokenization variations

A. Encode and decode

# Text -> token IDs
tokens = encoder.encode("Hello world")
print(tokens)

# Token IDs -> text
text = encoder.decode(tokens)
print(text)

B. Encode different types of text

# Different text can produce different token counts
examples = [
    "Hello",
    "Hello world!",
    "Artificial intelligence",
    "Tokenization is useful for LLMs."
]
for text in examples:
    tokens = encoder.encode(text)
    print(f"Text: {text}")
    print(f"Tokens: {tokens}")
    print(f"Count: {len(tokens)}\n")

C. Get individual token pieces

Sometimes you want to see the text represented by each token, rather than just its integer ID.

text = "The cat sat on the mat"

# Convert the text into token IDs
tokens = encoder.encode(text)

# Decode each token separately to inspect its text piece
for token_id in tokens:
    print(token_id, "->", encoder.decode([token_id]))

D. Compare tokenizers

import tiktoken

# Different models may use different encodings
for model in ["gpt-4o", "gpt-4"]:
    enc = tiktoken.encoding_for_model(model)
    tokens = enc.encode("Learning LLMs is fun!")
    print(model, len(tokens), tokens)

Models may share an encoding, so changing the model name does not necessarily change the token IDs.

Key points to remember

  • Token ID: An integer representing a token.
  • Vocabulary size: The number of token IDs available in an encoding.
  • Token count: The number of tokens in your particular text.
  • Encoding: Converts text into token IDs.
  • Decoding: Converts token IDs back to text.
  • Why it matters: Token counts affect context-window usage, API cost, and how much text you can send to a model.

2. Embeddings

An embedding converts text into a list of numbers (a vector) that represents its semantic meaning.

Unlike tokenization, which converts text into discrete token IDs, embeddings produce numerical representations that can help you compare meaning.

For example, these sentences have similar meanings:

  • "I love programming."
  • "Coding is something I enjoy."

Their embeddings may be close together in vector space.

Input text

"The Eiffel Tower is in Paris"

Embedding model

text-embedding-3-small

Vector

[-0.012, 0.034, 0.008, ...]

Illustrative values; actual vectors have many dimensions.

Main code: embedding.py

Install the required packages:

pip install openai python-dotenv

Create a .env file:

OPENAI_API_KEY=your_api_key_here
from openai import OpenAI
from dotenv import load_dotenv

# Load OPENAI_API_KEY from the .env file
load_dotenv()

# The SDK reads the API key from the environment
client = OpenAI()

text = (
    "Eiffel Tower is in Paris and is a famous landmark. "
    "It is 324 meters tall."
)

# Generate an embedding for the input text
response = client.embeddings.create(
    input=text,
    model="text-embedding-3-small"
)

# Extract the numerical vector from the response
vector = response.data[0].embedding
print("Embedding:", vector)
print("Vector dimensions:", len(vector))

The text-embedding-3-small model produces a vector with 1,536 dimensions by default. The output is a list of floating-point numbers, not readable text.

Embedding variations

A. Embed multiple sentences in one API request

Useful when processing several articles or documents.

texts = [
    "I love Python programming.",
    "JavaScript is used for web development.",
    "The Eiffel Tower is in Paris."
]
response = client.embeddings.create(
    input=texts,  # A list of texts
    model="text-embedding-3-small"
)
# Each result contains an embedding for one input
for item in response.data:
    print("Input index:", item.index)
    print("Vector dimensions:", len(item.embedding))

B. Reduce the number of dimensions

You can request a smaller vector to reduce storage requirements.

response = client.embeddings.create(
    input="I am learning artificial intelligence.",
    model="text-embedding-3-small",
    dimensions=512  # Request a 512-dimensional vector
)
vector = response.data[0].embedding
print("Dimensions:", len(vector))  # 512

C. Compare two embeddings

A common application is semantic similarity: checking how closely two sentences relate in meaning.

Install NumPy:

pip install numpy
import numpy as np

texts = [
    "I love programming.",
    "I enjoy writing code.",
    "The weather is sunny today."
]
response = client.embeddings.create(
    input=texts,
    model="text-embedding-3-small"
)
# Extract vectors in the same order as the input
v1, v2, v3 = [
    np.array(item.embedding) for item in response.data
]
def cosine_similarity(a, b):
    # Measure the angle-based similarity between two vectors
    return np.dot(a, b) / (
        np.linalg.norm(a) * np.linalg.norm(b)
    )
print("Similar meanings:", cosine_similarity(v1, v2))
print("Different topics:", cosine_similarity(v1, v3))

The first pair would generally be expected to have greater semantic similarity. The exact scores depend on the model and text.

What are embeddings used for?

Use caseHow embeddings help
Semantic searchFind documents by meaning, not just exact keywords
RAGRetrieve relevant document chunks for an LLM
RecommendationsFind related articles, products, or content
ClusteringGroup similar documents together
ClassificationUse vector representations as features

Remember this distinction: Tokenization prepares text in a token-based format for language-model processing. Embeddings represent text as vectors that are useful for semantic comparison and retrieval.

A natural next exercise is to combine both concepts: tokenize a document to understand its size, generate embeddings for its chunks, and compare those chunks with a user query. That's the foundation of a simple RAG application.
